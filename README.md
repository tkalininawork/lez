# Лес рук — посадочная страница

Статичная страница без сборки: `index.html` и папка `img/`.

Как опубликовать на GitHub Pages:
1. Загрузите содержимое этой папки в корень репозитория (index.html должен лежать в корне).
2. В репозитории откройте Settings → Pages, выберите ветку main и папку / (root), сохраните.
3. Через минуту-две страница будет доступна по адресу вида https://<имя>.github.io/<репозиторий>/.

Шрифты Philosopher и Ubuntu подключаются из Google Fonts.
